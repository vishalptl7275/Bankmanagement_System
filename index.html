BANKSYS / Project Showcase
Java Web Application

Bank Management
System

A web-based banking project for managing customer accounts and essential banking operations, built with Java, Jakarta Servlets, JDBC and MySQL.

View source code on GitHub ↗Setup instructions
Project preview — not a live banking applicationThis GitHub Pages website is a static showcase. Login, registration, account operations and database features require the Java server and MySQL database, which GitHub Pages cannot run. No real banking or customer data is processed here.

Key Features

Admin Authentication

Admin registration and login with BCrypt password hashing.

Customer Management

Create customer accounts and view customer records.

Balance Inquiry

Check account balances through the application.

Deposits & Withdrawals

Manage basic account deposit and withdrawal operations.

Fund Transfers

Transfer funds between customer accounts.

Database Storage

Persist application data using MySQL and JDBC.
